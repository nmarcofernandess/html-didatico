# HTML Didático

1. Leia [fontes e limites](../../references/fundamentos.md) e o
   [contrato HTML](../../references/html-portatil.md).
2. Siga o [playbook didático](../../references/playbooks/didatico.md): escolha
   manual ou editorial como modo interno e carregue só sua receita/exemplo.
   Para organização de sistemas, acrescente o [modo sistemas](../../references/playbooks/sistemas.md).
3. Reconstrua o significado quando necessário, desenhe cenas concretas e revise
   a expressão. Entregue o HTML com fontes e limites; inspecione o resultado real.

Para layout a decidir, use HTML Wireframe; montagem com contratos, HTML Blueprint;
evidência de execução, HTML Proof. Sem pedido HTML, uma explicação usa Explicar
com Clareza. Consulte o [roteamento](../../references/roteamento.md) se houver dúvida.
