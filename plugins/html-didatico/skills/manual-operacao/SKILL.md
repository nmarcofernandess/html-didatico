# Manual de operação · Direção A

Entrada direta para criar um manual ou quickstart; mantém a Direção A do HTML
Didático como fonte do estilo.

1. Leia a [skill principal](../html-didatico/SKILL.md), especialmente conteúdo
   antes de estética, narrativa, dioramas e verificação. A direção já está
   escolhida: A. Use as sub-skills de significado e escrita quando indicadas.
2. Consulte a [receita](../html-didatico/references/receita.md), §§1, 3, 4 e
   6–9, e o [manual de origem](../html-didatico/references/exemplos/A-manual-escalaflow-quickstart.html).
3. Use passos, comandos e textos da fonte real. Adapte a gramática visual,
   sem copiar dados do EscalaFlow para outro projeto.
4. Entregue o HTML autocontido, com navegação e dioramas verificados no navegador.

Esta entrada não executa os procedimentos descritos no manual por conta própria.
