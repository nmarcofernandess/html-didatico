# Prancha de decisão · Direção D

Entrada direta para comparar onde algo deve ficar ou como uma estrutura deve
ser organizada antes da implementação.

1. Leia a [skill principal](../html-didatico/SKILL.md), §2.2, a
   [receita](../html-didatico/references/receita.md), §11, e o
   [exemplo de prancha](../html-didatico/references/exemplos/D-prancha-unidade-exames.html).
2. Compare opções da mesma estrutura e mantenha o mesmo esqueleto visual.
   Use caixas neutras para conteúdo ainda não decidido, uma cor de revisão e
   hachura na região em disputa. Não invente conteúdo para preencher o desenho.
3. Mostre custos concretos, uma recomendação quando sustentada e as decisões
   que o leitor precisa tomar. Atualize a revisão ao incorporar correções.
4. Entregue o HTML autocontido e verifique a comparação nos tamanhos relevantes.

D tem tokens próprios. A prancha aprovada expressa intenção de produto, não
componentes já implementados nem autorização para implementar a proposta.
