# HTML Proof

1. Leia [fontes e limites](../../references/fundamentos.md) e o
   [playbook Proof](../../references/playbooks/proof.md) antes de criar ou editar HTML.
2. Descubra o renderer e seu contrato. Com renderer oficial, siga o caminho do
   projeto e trabalhe no template/CSS quando autorizado. Pack ausente continua
   nesse caminho; não gere um substituto manual apresentado como oficial.
3. Somente sem renderer confirmado use o fluxo manual de planejamento e
   preenchimento do playbook, com comandos/aceites reais e resultados observados.
4. Confira veredito, etapas, evidências e fontes; aplique o
   [contrato HTML](../../references/html-portatil.md) compatível com o projeto.

Esta skill unifica prova-final e proof-html. Uma explicação que cita provas não
vira proof; maquete de tela usa HTML Wireframe. Veja o [roteamento](../../references/roteamento.md).
